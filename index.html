📱 Quantified Self – Screen Time Dashboard

Created by: Rishabh Bansal

Profile: 32-Year-Old Indian Male (Fictional Dataset)

Written Project Report (Embedded in Dashboard)

Page 1: Data Collection & Objectives

This project is based on the Quantified Self concept, which focuses on using personal data to understand and improve daily habits through visualization. For this dashboard, I created a fictional dataset representing the daily screen time usage of a 32-year-old Indian male over a 14-day period. This data includes total screen time in hours, types of applications used, and time-of-day usage patterns.

The main objective of this project is to explore how screen time impacts productivity, sleep quality, and digital well-being. I chose screen time as a focus area because it strongly affects modern lifestyle, mental health, and work-life balance. The data was structured manually to simulate realistic daily behavior patterns.

Page 2: Tools, Storage & Visualization Methods

The data was stored directly within the website code using JavaScript arrays. This approach was chosen because it allows easy access to the data without relying on external databases. For visualization, I used HTML, CSS, JavaScript, and the Chart.js library, which provides interactive and responsive graphs.

Multiple types of visualizations were used including line charts, pie charts, bar charts, and scatter plots. Each visualization was chosen based on its suitability for showing trends, comparisons, distributions, and correlations. An interactive dropdown filter was added to allow users to explore screen time data based on weekdays and weekends.

Page 3: Analysis & Insights

From the visual analysis, it is observed that screen time is generally higher during weekends compared to weekdays. The line chart shows a noticeable upward trend in screen usage on Saturdays and Sundays. The pie chart reveals that social media and work-related applications consume the majority of screen time.

The scatter plot comparing screen time and sleep duration shows a negative correlation, meaning that higher screen time is often associated with reduced sleep hours. This dashboard demonstrates how data visualization can help individuals become more aware of their habits and make better lifestyle decisions based on data-driven insights.

Data-Driven Questions

2. Do weekdays have higher screen time compared to weekends?

4. At what time of day is screen usage highest?
