📱 Quantified Self – Screen Time Dashboard

Course: ANLY 512 – Data Visualization

Created by: Rishabh Bansal

Written Project Report

Page 1: Data Collection & Objectives

This project follows the Quantified Self concept, where I track and analyze my own daily screen time to better understand my digital habits. I collected data over a period of time by monitoring my phone and device usage and recording the number of hours spent on different applications and activities each day.

The main goal of this project is to understand how my screen usage affects my productivity, focus, and overall well-being. By visualizing my own data, I am able to reflect on my habits and identify patterns that would not be obvious from raw numbers alone.

Page 2: Tools, Storage & Visualization Methods

I stored my data directly inside the website code using JavaScript arrays. This approach was chosen because it makes the dashboard simple, lightweight, and easy to deploy on a web platform. No external databases were required.

For visualization, I used HTML, CSS, JavaScript, and the Chart.js library. Different types of charts were used to communicate different insights: line charts for trends, bar charts for comparisons, pie charts for distribution, and scatter plots for relationships between variables. I also added an interactive dropdown to allow filtering of data by type of day.

Page 3: Analysis & Insights

The visualizations show that my screen time tends to increase during weekends compared to weekdays. I noticed clear patterns where social media and work-related applications occupy a large portion of my daily usage.

The comparison between screen time and sleep duration shows that when my screen usage is higher, my sleep duration tends to decrease. This dashboard helped me become more aware of my habits and gave me actionable insights to better manage my time and digital well-being.

Data-Driven Questions

1. How does my daily screen time vary over time?
2. Do I spend more time on screens during weekdays or weekends?
3. Which app categories take up most of my screen time?
4. At what time of day do I use my devices the most?
5. Does increased screen time impact my sleep duration?
